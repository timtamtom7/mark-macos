# Mark

A screenshot annotation tool for macOS.

## What it does

- Capture
- annotate
- hotkeys
- export
- iCloud sync

## Targets

- macOS with widgets

## Structure

Key types:

- ``AnnotationService`/`AnnotationRenderer`/`AnnotationStorage``
- ``HotKeyManager``
- ``ShortcutRecorderView``
- ``CloudExportService``
- ``PrivacyService``

Recap is the other annotation tool here, but for video rather than stills.

## Status

Apple-platform experiment built to explore what an AI coding agent could produce for a native app. Not actively maintained.

Xcode projects here were generated with XcodeGen (`project.yml`) unless noted; open the `.xcodeproj` directly.
